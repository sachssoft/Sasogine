# Frame Set Markup Example

Sasogine supports frame set markup documents in XML and JSON format.

The examples are based on exports generated by [Free Texture Packer](https://github.com/odrick/free-tex-packer?utm_source=chatgpt.com).

## XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<TextureAtlas imagePath="editor_icons.png" width="512" height="512" scale="1" format="RGBA8888">
  <sprite n="editor_cursor_selection" x="0" y="0" w="72" h="72" pX="0.5" pY="0.5" oX="0" oY="0" oW="72" oH="72" r="n" />
  <sprite n="editor_tab_hole" x="72" y="0" w="62" h="72" pX="0.5" pY="0.5" oX="5" oY="0" oW="72" oH="72" r="n" />
</TextureAtlas>
```

## Mapping

| `FrameSetEntry`      | XML     | JSON                 |
| -------------------- | ------- | -------------------- |
| `Name`               | `n`     | `filename`           |
| `X`                  | `x`     | `frame.x`            |
| `Y`                  | `y`     | `frame.y`            |
| `Width`              | `w`     | `frame.w`            |
| `Height`             | `h`     | `frame.h`            |
| `IsRotated`          | `r`     | `rotated`            |
| `IsTrimmed`          | derived | `trimmed`            |
| `SpriteSourceX`      | `oX`    | `spriteSourceSize.x` |
| `SpriteSourceY`      | `oY`    | `spriteSourceSize.y` |
| `SpriteSourceWidth`  | `oW`    | `spriteSourceSize.w` |
| `SpriteSourceHeight` | `oH`    | `spriteSourceSize.h` |
| `SourceWidth`        | `oW`    | `sourceSize.w`       |
| `SourceHeight`       | `oH`    | `sourceSize.h`       |
| `PivotX`             | `pX`    | `pivot.x`            |
| `PivotY`             | `pY`    | `pivot.y`            |

## Loading

```csharp
var loader = FrameSetLoader.Create(
    DocumentFormatType.Json,
    source).Load();

foreach (var entry in loader.Entries)
{
    // Use frame information.
}
```

Direct conversion:

```csharp
var frameSet = FrameSetLoader
    .Create(DocumentFormatType.Json, source)
    .ToKeyed(texture);
```

Enumeration:

```csharp
var frameSet = FrameSetLoader
    .Create(DocumentFormatType.Xml, source)
    .ToIndexed<MyFrames>(texture);
```

The markup format is independent of the resulting `FrameSetEntry` objects, allowing additional markup formats to be added without changing the frame set API.
