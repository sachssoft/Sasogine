## [0.0.4-alpha] - In progress
- [Feature] Added a Vector Path Tool with `VectorPathTool` for creating and editing vector paths.
- [Feature] Added Selection and Transformation Tools with `SelectionTool` for editing and transforming objects.
- [Feature] Added object insertion support with `ObjectInsertTool` for creating and placing objects in the editor.
- [Feature] Initial alpha release
- [Feature] Initial Sasogine toolkit release
