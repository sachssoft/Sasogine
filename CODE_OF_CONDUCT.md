# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and constructive environment for everyone participating in the Sasogine project.

Contributors, users, maintainers, and other community members are expected to interact professionally and respectfully.

## Expected Behavior

Examples of positive and constructive behavior include:

* Treating others with respect and consideration.
* Providing constructive and technical feedback.
* Respecting different opinions, experiences, and levels of expertise.
* Keeping discussions focused on the project and the issue being discussed.
* Accepting reasonable technical criticism and corrections.
* Helping maintain a productive environment for collaboration.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, threats, intimidation, or personal attacks.
* Discriminatory or insulting comments.
* Deliberate disruption of discussions, issues, or pull requests.
* Publishing private or personally identifiable information without permission.
* Repeated hostile or inappropriate communication.
* Spam, advertising, or unrelated promotional content.
* Any other conduct that would reasonably be considered inappropriate in a professional open-source project.

## Technical Discussions

Technical disagreements are normal and welcome.

Discussions should focus on code, architecture, APIs, performance, documentation, or other aspects of the project rather than on the individuals involved.

Maintainers may close discussions that become unproductive, hostile, or unrelated to the project.

## Maintainer Responsibilities

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Maintainers may edit or remove comments, commits, issues, pull requests, or other contributions that violate these guidelines.

Depending on the circumstances, maintainers may issue a warning, temporarily restrict participation, or permanently remove a participant from project spaces.

## Reporting

If you experience or observe behavior that violates this Code of Conduct, please report it privately to the project maintainers.

Reports will be reviewed as reasonably and confidentially as possible.

## Scope

This Code of Conduct applies to all official Sasogine project spaces, including:

* GitHub issues
* Pull requests
* Discussions
* Code reviews
* Other communication channels officially associated with the project

## Enforcement

Violations may result in actions considered appropriate by the project maintainers, including warnings, removal of content, temporary restrictions, or permanent exclusion from the project community.

## Attribution

This Code of Conduct is intended to provide simple and practical community guidelines for the Sasogine open-source project.
