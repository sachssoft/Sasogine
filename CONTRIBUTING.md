# Contributing to Sasogine

Thank you for your interest in Sasogine.

Sasogine is publicly available as an open-source project, while its core
development and architectural direction are currently maintained by the
project owner.

## Bug Reports

Bug reports are welcome.

Please use GitHub Issues to report reproducible problems with Sasogine.

When possible, include:

-   Sasogine version
-   .NET version
-   Operating system
-   Rendering backend
-   Steps to reproduce
-   Expected behavior
-   Actual behavior
-   Relevant exception messages or stack traces
-   Minimal reproduction code

## Questions

For questions about Sasogine, its architecture, APIs, or usage, please
use GitHub Discussions.

GitHub Issues should primarily be used for actual bugs and clearly
identifiable problems.

## Ideas and Suggestions

Ideas and feature suggestions are welcome through GitHub Discussions.

Suggestions may influence future development, but submitting an idea
does not guarantee implementation.

Architectural decisions remain under the control of the Sasogine project
owner.

## Pull Requests

External pull requests are currently not part of the normal Sasogine
development workflow.

Please open a Discussion or Issue before proposing source-code changes.

Implementation and integration of changes are maintained by the project
owner to preserve consistency of the architecture and public API.

## Coding Standards

Sasogine follows coding and architectural conventions based on
established .NET standards.

See:

-   `CODING_STYLE.md`
-   `PROGRAMMING_ARCHITECTURE_GUIDELINES_EN.md`

These rules should also be considered when providing code examples, bug
reproductions, or technical suggestions.

## Documentation

Corrections and suggestions regarding documentation are welcome through
GitHub Issues or Discussions.

This includes:

-   Incorrect documentation
-   Missing API explanations
-   Outdated examples
-   Typographical errors
-   Unclear descriptions

## Community

Constructive technical discussion is welcome.

The goal is to keep Sasogine development focused while providing an open
place for users to report problems, ask questions, and suggest
improvements.
